YS SCHOLARIA WEBSITE - ONE FOLDER

Everything for the website is in this single folder. There are no sub-folders.

TO PUBLISH
1. Upload all the files in this folder to the ROOT of your hosting for ysscholaria.com
   (the same place index.html goes). Code.gs and SETUP.txt are setup files and do not need to be uploaded.
2. Optional, recommended: turn on live visitor and request counters, orders and reviews.
   Follow SETUP.txt, paste the web app URL into config.js, and upload config.js again.
3. Open the site on your phone and computer to check it.

WHAT THE FILES ARE
- *.html: the website pages (index.html is the home page)
- config.js: connection settings. This is the only file you edit.
- pay-*.png: payment method logos
- sample-*: sample CV and research proposal structure
- mark.png, mark-white.png, founder.jpg: logo and founder photo
- favicon.ico, favicon-32x32.png, icon-192.png, icon-512.png, apple-touch-icon.png: browser tab and home screen icons
- og-image.png: picture shown when someone shares the website link
- site.webmanifest, sw.js: install-as-app support
- robots.txt, sitemap.xml: search engine files
- Code.gs, SETUP.txt: backend setup (not part of the website)
